# Ikai One — Shipper Dashboard

Responsive shipper-panel frontend built with React, Vite, Tailwind CSS, React Router, Recharts, and lucide-react.

## Run locally

```bash
cd shipper-dashboard
npm install
npm run dev
```

Production build: `npm run build`

## Scope
- Dashboard and sidebar modules for orders, shipments, returns, NDR management, courier partners, pickup addresses, shipping rules, billing/wallet, analytics, integrations, support, and settings.
- Mock data only. No backend, authentication, live courier API, or persistent storage is connected.
- UI actions that require a server are demo alerts.
